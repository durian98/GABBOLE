# 시스템 구성도 기술 로고

확인일: 2026-10-20

모든 아이콘은 배경이 투명한 SVG입니다. `architecture.svg`에는 각 원본의 벡터 경로를 직접 넣었으므로 외부 이미지 서버나 별도 파일 로딩에 의존하지 않습니다. 구성도 안의 크기·위치·단색 표시를 조정했습니다.

- Simple Icons 배포물: [CC0 1.0](SIMPLE-ICONS-LICENSE.txt). 각 브랜드의 상표·로고 권리는 해당 권리자에게 있으며, 배포 라이선스와 별개입니다. [Simple Icons 안내](SIMPLE-ICONS-DISCLAIMER.txt)를 함께 보관합니다.
- Java 로고: Devicon의 원본 색상 SVG, [MIT](DEVICON-LICENSE.txt). 원본 로고의 권리는 해당 권리자에게 있습니다.
- Jenkins 로고: [Jenkins 공식 Artwork](https://www.jenkins.io/artwork/), 원본 디자인 Frontside, [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/).
- MinIO 로고는 S3 호환 저장 어댑터에서 사용하는 **MinIO SDK**를 표시합니다. 특정 운영 저장소 제공자나 서버 배치를 확정하는 표시는 아닙니다.
- OR-Tools는 Python 아이콘 옆에 이름으로 표시했습니다. 독자적인 브랜드 로고를 새로 만들지 않았습니다.
